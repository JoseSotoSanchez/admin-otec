# Ready for Development

## Instalando dependencias

Para poner en marcha el sistema primero se debe instalar [poetry](https://python-poetry.org/). Poetry es un gestor de dependencias de Python el cual ayudará a instalarlas rapidamente y evitará errores.

## Ejecutando el proyecto

Una vez instalado se deben ejecutar los siguientes comandos en consola:

1. make install (para instalar las dependencias listadas en el archivo pyproject.toml).
2. make run (para ejecutar el proyecto utilizando el entorno virtual .venv instalado por poetry).
